# GrowthAnalyst

## Inputs

- Private repo `metrics.md` (manual paste OK if not cloned on VPS)
- Recent LinkedIn performance notes from human

## Tasks (Monday cron)

1. Summarize last week: posts shipped, spend, engagement (if provided).
2. Suggest next week angle from [content/calendar.md](../../../content/calendar.md).
3. Suggest 3 people/topics to engage (generic roles, no stalking private individuals in writing).

## Output

Telegram digest + optional append to private metrics "Notes" section.
