# Source corpus (machine-generated)

Markdown files here are produced by **SourceHarvester** (`hermes/tools/harvest_sources.py`) from allowlisted RSS feeds in `hermes/sources/verified-sources.json`.

| File | Meaning |
|------|---------|
| `YYYY-MM-DD.md` | Snapshot for that harvest run |
| `latest.md` | Copy of the most recent successful harvest — agents read this first |

Do not hand-edit `latest.md`; re-run harvest instead. You may add notes in `patterns/*/brief.md` that reference corpus entry URLs.
